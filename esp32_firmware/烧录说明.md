# ESP32 摄像头图传烧录指南

这份 `esp32_firmware.ino` 是你队友需要烧录到 XIAO ESP32S3 (Sense) 板子上的 C++ 代码。它的作用是让摄像头拍下画面，并在同一个局域网内广播出来给电脑端接收。

## 烧录步骤：

1. **安装 Arduino IDE**
   如果你队友还没装，让他去官网下载 Arduino IDE（https://www.arduino.cc/en/software）。

2. **添加 ESP32 开发板支持**
   在 Arduino 的“首选项”-“附加开发板管理器网址”里填入：`https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   然后去“开发板管理器”搜索并安装 `esp32` 库。

3. **修改代码里的 Wi-Fi**
   用 Arduino IDE 打开 `esp32_firmware.ino`这个文件。
   把代码第 9 行和第 10 行的 `YOUR_WIFI_NAME` 和 `YOUR_WIFI_PASSWORD`，换成你们测试用的手机热点（或是实验室 Wi-Fi）的账号和密码。

4. **主板设置和烧录**
   * 开发板选择：`XIAO_ESP32S3`
   * PSRAM 选择：`OPI PSRAM` （XIAO ESP32S3 Sense 有额外的内存，必须开启）
   * 插上数据线，点击左上角的“上传(Upload)”按钮。

5. **获取摄像头的 IP 地址**
   烧录成功后，点击 Arduino IDE 右上角的“串口监视器”(波特率选 115200)，按一下板子上的 Reset 按钮。
   如果有信息弹出，它会告诉你类似于：`CAMERA_ID = "http://192.168.1.100:81/stream"` 的连接地址。

6. **打通电脑和硬件**
   让队友把上面那串地址，原封不动地替换到电脑端大工程的 `src/config.py` 里的 `CAMERA_ID = ...` 变量上。
   然后你们运行电脑的代码，就能看到小板子拍的画面并进行 AI 识别了！
