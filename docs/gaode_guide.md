# 高德地图 API 配置指南

既然您想要使用真实的导航功能，我们需要获取高德地图的 **Web服务 API Key**。这是一个免费的过程，请跟随以下步骤操作：

## 第一步：注册与创建应用

1.  **访问官网**：打开 [高德开放平台](https://console.amap.com/dev/index)。
2.  **注册/登录**：使用您的手机号注册或登录高德开发者账号。
3.  **进入控制台**：登录后，点击右上角的“控制台”。
4.  **创建新应用**：
    *   在左侧菜单点击 **“应用管理”** -> **“我的应用”**。
    *   点击右上角的 **“创建新应用”** 按钮。
    *   **应用名称**：填写“盲人辅助系统”或任意名称。
    *   **应用类型**：选择“工具”或“其他”。

## 第二步：添加 Key

1.  在您刚才创建的应用下方，点击 **“添加”**（或右上角的+号）来添加一个 Key。
2.  **Key名称**：填写“Navigation”或任意名称。
3.  **服务平台**：**非常重要**，请选择 **【Web服务】** (不是Web端(JSAPI)，也不是Android SDK)。
    *   *注意：我们要用的是Python后台调用接口，所以必须选“Web服务”。*
4.  **同意协议并提交**。

## 第三步：获取 Key 并配置

1.  提交后，您会在列表中看到刚刚创建的 Key。
2.  找到 **“Key”** 这一列，它是一串长的字符（例如 `a1b2c3d4...`）。
3.  **复制** 这串 Key。

## 第四步：填入系统

1.  打开项目中的 **`config.py`** 文件。
2.  找到 `AMAP_API_KEY` 这一行。
3.  将您的 Key 粘贴进去，替换掉原来的 `"YOUR_AMAP_KEY"`。

**示例：**
```python
# config.py
AMAP_API_KEY = "您的实际Key密钥写在这里" 
```

## 额外说明：关于定位

由于电脑通常没有GPS模块，我们启用真实的“IP定位”功能。
*   **IP定位**：高德会根据您连接的WiFi网络估算这台电脑的大致位置（误差可能在几百米到几公里）。
*   **如何更准？**：如果不准，您可以在语音导航时直接告诉系统起点，例如说：“从**天安门**导航到**故宫**”。
