摘要：针对现有视障辅助设备在复杂场景理解与人机交互方面的局限性，本文提出了一种融合轻量级目标检测网络与多模态大语言模型 (Multimodal Large Language Model, MLLM) 的新型辅助系统架构。该系统以 YOLOv11n 为视觉感知核心，实现了对动态障碍物的毫秒级检测；提出了基于单目视觉几何的碰撞风险评估模型 (CRAM)，有效解决了单目测距的难题。进一步地，本文创新性地引入 Qwen-VL 视觉大模型构建智能代理 (Agent)，赋予系统对非结构化场景的深度语义理解能力。实验表明，该系统在端侧设备上可达 20 FPS 的实时处理速度，在多场景下的交互准确率优于传统方案，具有重要的工程应用价值。

关键词：计算机视觉；YOLOv11；多模态大模型；视觉辅助；人机交互；Flask可视化

1. 引言 (Introduction)

视障人士的独立出行是社会无障碍建设的重要组成部分。传统的超声波雷达或导盲杖无法提供语义信息（如“前方是红绿灯”或“这是什么路障”）。近年来，基于 CNN 的视觉辅助方案虽然在物体识别上取得了进展，但仍存在两大瓶颈：一、缺乏场景理解，只能识别预定义的物体；二、交互方式僵化，缺乏自然语言交互能力。

鉴于此，本文复现并改进了基于 YOLOv11 + Qwen-VL 的双流架构，旨在构建一个既具备实时避障能力，又拥有开放世界理解能力的智能辅助系统。

2. 方法论 (Methodology)

2.1 系统整体架构

本系统采用“端云协同 + 异步并发”架构：

  • 快系统 (Fast System):基于 YOLOv11n 运行于本地 CPU/GPU，负责高频 (20Hz) 的障碍物检测与急停预警。
  • 慢系统 (Slow System):基于 Qwen-VL 运行于云端，负责低频 (0.5Hz) 的通用场景问答与语义推理。

2.2 基于单目几何的风险评估模型 (CRAM)

为解决单目摄像头缺乏深度信息的问题，本文构建了基于透视投影原理的风险评估模型。设检测框 B 的面积为 S_box，图像总面积为 S_frame，则目标的风险系数 R 定义为：

R = α · (S_box / S_frame) + β · I_class

其中 α 为距离权重系数，I_class 为类别危险指数。当 R 超过阈值时，系统触发最高优先级 (P0) 的语音阻断警报。

def speak(text, priority):
    if priority == 0 (CRITICAL):
        Q.clear()  # 立即清空低优先级消息
        stop_current_speech()

    else:
        Q.push(text, priority)

本文成功复现并扩展了基于 YOLOv11 的盲人辅助系统。相比于传统的单一视觉方案，本系统通过引入大模型 Agent，有效拓展了系统的感知边界。Web 可视化平台的加入，更是为远程监护提供了数据支撑。
